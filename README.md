HTML
CSS
Java Script

## Features
Randomly moving target
Live score count
30 sec countdown timer
Target speed increases after every 5 successful hits
Restart game button
Hit Sound
Miss Sound
Modern and Responsive user interface

## Technologies Used
-HTML
-CSS3
-JavaScript

## How to play

1. Open ""index.html"" in web browser
2. Click on moving target to earn points
3. Target becomes faster every 5 hits
4. Clicking anywhere else inside the game area ends the game immediately
5. Click ""Restart Game"" to play again
